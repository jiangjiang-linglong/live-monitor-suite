# 抖音直播监控 —— 飞书自建应用配置指引

> 目的：让配置同步服务用「企业自建应用」身份直接读写多维表，**不再依赖豆包会话的临时凭证**，实现 7×24 独立运行。

## 为什么这样能摆脱依赖

| 对比项 | 旧方案（lark-cli + 会话凭证） | 新方案（自建应用） |
|---|---|---|
| 认证载体 | 豆包会话注入的临时 token | 应用的 App ID / App Secret |
| 有效期 | 未知，会话关闭可能失效 | 长期有效（除非主动重置密钥） |
| token 刷新 | 靠重新打开豆包/对话 | 服务自动获取、自动刷新（2 小时） |
| 运行条件 | 必须有活跃豆包会话 | 无，launchd 独立运行 |

## 操作步骤（约 5 分钟，一次性）

### 1. 进入开发者后台
浏览器打开 https://open.feishu.cn/app ，**确认右上角登录的是「多维表所在」的飞书账号/租户**。

### 2. 创建企业自建应用
- 点击 **创建企业自建应用**
- 名称填「抖音直播监控」（可自定义），填一句描述，创建
- 创建后进入应用详情页，记下 **App ID**（`cli_` 开头）和 **App Secret**

### 3. 开通多维表权限
- 左侧菜单 **权限管理** → **开通权限**
- 搜索并勾选：**查看、评论、编辑和管理多维表格（bitable:app）**
- 确认开通

### 4. 发布应用
- 左侧 **版本管理与发布** → **创建版本**
- 填版本号（如 1.0.0）和更新说明 → **发布**
- 若提示需管理员审核，等待通过；本人是管理员可直接通过

### 5. 把应用添加为多维表协作者（关键）
- 打开监控用的多维表
- 右上角 **···** → **···更多** → **添加文档应用**
- 搜索第 2 步创建的应用名，添加，权限选 **可编辑 / 可管理**
- > 注意：必须先完成第 3 步（开通 bitable 权限），否则在窗口里搜不到应用。

### 6. 填入凭证
把 App ID / App Secret 填入 `config_sync/feishu_app.json`（可由助手代填，权限 600）：

```json
{
  "app_id": "cli_xxxxxxxx",
  "app_secret": "xxxxxxxx",
  "base_token": "Uc8Qbxvh0aoeYas9p0icAmpInjh"
}
```

填好后同步服务下一轮（≤60 秒）即生效，无需重启电脑。

## 部署到客户租户时
在客户的飞书租户里重复上述 1–5 步，并把 `base_token` 换成客户的多维表 AppToken。
